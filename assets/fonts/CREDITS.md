# Fuentes

- `NotoSansJP-Subset.otf`: subconjunto (solo los caracteres que usa el juego) de Noto Sans CJK JP
  Medium. Copyright The Noto Project Authors / Adobe. Licencia SIL Open Font License 1.1
  (https://scripts.sil.org/OFL). Se usa como respaldo del japonés.
- `NotoSansDevanagari-Medium.ttf`: Noto Sans Devanagari Medium (paquete npm `@fontsource/noto-sans-devanagari`,
  convertido de WOFF a TTF sin cambios). Copyright 2022 The Noto Project Authors
  (https://github.com/notofonts/devanagari). Licencia SIL Open Font License 1.1. Se usa como respaldo del hindi.

Las dos se usan sin modificar su nombre ni vender las fuentes por separado, como pide la OFL.
